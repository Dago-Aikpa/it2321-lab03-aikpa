# IT-2321 Lab 3: Processing Data with Higher-Order Functions

**Reading: Eloquent JavaScript, Chapter 5**

This lab is practice with using map, filter, and reduce, and writing a higher-order function of your own.

## Getting started

1. Rename this repository to `it2321-lab03-lastname` (your last name, all lowercase) and set it to Private.
2. Clone it and open the folder in Visual Studio Code.
3. Open `index.html` in your browser, and open the developer console to see your output.
4. Write your code in `script.js`, replacing each `TODO` with your own work.

## What to do

- Use filter() to select a subset of the dataset.
- Use map() to transform the dataset into new values.
- Use reduce() to combine the dataset into a single value.
- Write at least one higher-order function of your own.
- Aim for code that reads clearly, not the shortest possible solution.

## Files

- `index.html` — the page that loads your script. You usually do not need to change much here.
- `script.js` — where your work goes.
- `styles.css` — basic styling you may adjust.
